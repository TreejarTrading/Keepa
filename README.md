# KEEPA — сервис поиска и аналитики товаров Amazon

MCP-сервер, который ищет товары на Amazon через **Keepa API** на 6 рынках
(**US, UK, DE, FR, IT, ES**), вытягивает метрики для принятия решения о
закупке (история цен, скорость продаж, конкуренция, рейтинги, характеристики)
и формирует **XLSX-отчёты** в папку `Products/`. Анализ и вердикт
**BUY / WATCH / SKIP** выносит Claude через `/mcp` по правилам из
[SEARCH_GUIDE.md](SEARCH_GUIDE.md); кроме того, есть авторежим, который сам
прогоняет сохранённые поиски каждые 2 дня.

После того как товар отобран (через Keepa или из ваших данных по рынку Amazon),
сервер помогает **найти этот товар в Китае** — на **1688, Alibaba.com,
Taobao/Tmall, Pinduoduo** — и его цену предложения, с оценкой маржи. Цель
мэтчинга — 100% тот же товар (EXACT), иначе ищем похожие (SIMILAR). Поскольку
открытого API у этих площадок нет, **Claude сам ищет на сайтах** (WebSearch /
WebFetch / поиск по картинке), а сервер строит план поиска, классифицирует
найденные предложения и сохраняет отчёт по сорсингу. Подробно —
[SOURCING_GUIDE.md](SOURCING_GUIDE.md).

## Установка

Нужен [`uv`](https://docs.astral.sh/uv/) (или обычный `pip`) и Python ≥ 3.10.

```bash
uv venv
uv pip install -e .
```

## Настройка

1. **Ключ Keepa** ([получить](https://keepa.com/#!api)) — любой из вариантов:
   - файл `ENV DOCS` в корне проекта (строка `KEEPA_API_KEY=ключ` или просто
     ключ одной строкой) — подхватывается автоматически;
   - файл `.env` (скопировать из `.env.example`);
   - переменная окружения `KEEPA_API_KEY`.

2. Маркетплейс по умолчанию — **US**. Менять — `KEEPA_DOMAIN`
   (US/UK/DE/FR/IT/ES, также JP/CA/IN/MX/BR; «UK» автоматически
   транслируется в код Keepa `GB`).

3. Отчёты пишутся в `<repo>/Products` (на рабочей машине —
   `/home/andrea/KEEPA/Products`). Переопределить — `KEEPA_OUTPUT_DIR`.

Проверка установки одной командой:

```bash
uv run python check_setup.py
```

## Запуск через `/mcp` в Claude Code

Файл `.mcp.json` уже описывает сервер. Откройте Claude Code в папке проекта,
выполните `/mcp` — сервер `keepa` появится в списке. Примеры запросов:

> «Найди новые товары» — поиск по базовому профилю из SEARCH_GUIDE.md.
>
> «Выбери категорию kitchen и найди в ней товары» — поиск категории,
> бестселлеры, затем отбор по фильтрам.
>
> «Найди беспроводные наушники до $40, рейтинг от 4.3, от 500 отзывов, в US и
> DE» — поиск по заданным фильтрам на нескольких рынках.
>
> «Запусти авто-поиск» — прогон всех сохранённых поисков из auto_searches.json.

Claude вызовет инструменты сервера, проанализирует метрики, даст вывод —
стоит ли заходить в категорию и продавать товар — и сохранит XLSX в `Products/`.

### Инструменты MCP

| Инструмент | Назначение |
|---|---|
| `server_info` | Текущая конфигурация (рынки, папка отчётов, наличие ключа). |
| `token_status` | Остаток токенов Keepa (квота). |
| `search_products` | Поиск через Keepa Product Finder + метрики по найденным ASIN. Доп. фильтры — через `extra_filters`. |
| `search_multi_market` | Тот же поиск сразу по нескольким рынкам (по умолчанию US→UK→DE→FR→IT→ES). |
| `find_categories` | Поиск ID категорий Amazon по названию (ID различаются по рынкам). |
| `category_best_sellers` | Бестселлеры категории с полными метриками. |
| `get_products` | Полные метрики и характеристики по известным ASIN. |
| `analyze_and_report` | Загрузить метрики по ASIN, сразу сохранить отчёт, вернуть данные. |
| `save_report` | Сохранить XLSX-отчёт с вердиктами, проставленными Claude. |
| `run_auto_search` | Прогнать сохранённые поиски из `auto_searches.json` прямо сейчас. |
| `china_sourcing_plan` | Построить план поиска товара в Китае (по ASIN из Keepa и/или вашим товарам): ссылки и запросы для 1688/Alibaba/Taobao/Tmall/Pinduoduo. |
| `match_china_offers` | Оценить найденные предложения из Китая: EXACT vs SIMILAR, себестоимость в USD и маржа к цене Amazon. |
| `fetch_page` | Запасной best-effort GET страницы (китайские сайты часто блокируют ботов — основной путь это WebSearch/WebFetch Claude). |
| `save_sourcing_report` | Сохранить XLSX-отчёт по сорсингу (листы «Сорсинг» и «Сводка»). |

## Авторежим: поиск каждые 2 дня

Сохранённые поиски (категории + фильтры + рынок) лежат в `auto_searches.json`
(формат — в [SEARCH_GUIDE.md](SEARCH_GUIDE.md)). Запуск вручную:

```bash
uv run keepa-auto
```

По расписанию раз в 2 дня в 09:00 (`crontab -e`):

```
0 9 */2 * * cd /home/andrea/KEEPA && uv run keepa-auto >> auto_search.log 2>&1
```

Каждый прогон кладёт по одному XLSX на поиск в `Products/` с автоматическими
вердиктами BUY/WATCH/SKIP (правила — те же сигналы, что в SEARCH_GUIDE.md).

## Сорсинг в Китае (1688 / Alibaba / Taobao / Pinduoduo)

После отбора товара — найти его в Китае и цену предложения. У китайских площадок
нет открытого API, поэтому **Claude сам ищет на сайтах** (WebSearch / WebFetch /
поиск по картинке), а сервер даёт «леса»:

1. `china_sourcing_plan(asins=[...])` или `china_sourcing_plan(products=[...])`
   — строит по каждому товару ссылки и запросы для всех площадок и гайд, как
   искать (перевести название на китайский, искать по фото для 100% совпадения).
2. Claude ищет на 1688/Alibaba/Taobao/Pinduoduo, собирает предложения
   (поставщик, цена, MOQ, ссылка, подтверждение по фото).
3. `match_china_offers(product, offers, freight_pct=0.15)` — классифицирует
   **EXACT** (тот же товар, ~100%) vs **SIMILAR** (похожий), считает
   себестоимость в USD и маржу к цене Amazon, сортирует лучшее вперёд.
4. `save_sourcing_report(results)` — XLSX в `Products/` (листы «Сорсинг» и
   «Сводка»).

Курсы валют и площадки настраиваются через env (`CHINA_PLATFORMS`,
`CHINA_USD_PER_CNY`, `CHINA_FREIGHT_PCT`, `CHINA_EXACT_THRESHOLD`). Подробная
инструкция — [SOURCING_GUIDE.md](SOURCING_GUIDE.md).

## Метрики и логика решения

Сервер возвращает по каждому товару:

- **Цены**: текущая/средняя/мин/макс и волатильность для New, Amazon, Buy Box, FBA.
- **Скорость продаж**: текущий sales rank и число просадок ранга за 30/90 дней
  (прокси числа продаж), оценка `monthlySold`.
- **Конкуренция**: число офферов, держит ли Buy Box сам Amazon.
- **Спрос/удовлетворённость**: рейтинг и его динамика, число и скорость отзывов.
- **Характеристики**: бренд, категория, фичи, описание, габариты/вес, вариации,
  оценка комиссий FBA; ссылки на amazon нужного рынка и keepa.com.

Вместе с данными отдаётся `DECISION_GUIDANCE` — набор сигналов «за» и «против»,
чтобы вердикты Claude были единообразными. Критерии и пороги — в
[SEARCH_GUIDE.md](SEARCH_GUIDE.md). Итоговое решение всегда за Claude
(в авторежиме — по тем же правилам автоматически).

## Безопасность

`.env` и `ENV DOCS` с ключом Keepa в git не попадают (`.gitignore`).
XLSX-отчёты тоже игнорируются — в репозитории остаётся только сама папка
`Products/`.
