## 4. Экономика (ядро, под-ниша A)

Пример Vtopmart $20.18: FBA pick&pack $7.46 + referral ~15% ($3.03) ≈ **$10.49 заберёт Amazon**, остаётся ~$9.7 до COGS.
COGS с Alibaba для 25-pc сета ≈ **$1.8–4.0** (см. §6) + ввоз/логистика. → **Валовая маржа здоровая (40–55%)**, ниша экономически рабочая.
A-LuGei держит $14.99 при FBA $6.48 (легче 760 г) — выигрывает на логистике и цене входа.

## 5. Вывод

**Спрос — большой и стабильный** (топ-листинг 20k шт/мес, ещё 2–3 по 8–10k; рейтинги 4.4–4.8). **Экономика положительная.**

**НО главный барьер — review-moat:** Vtopmart 48.5k и WOWBOX 14.3k отзывов. Лобовая копия «ещё один 25-pc прозрачный сет» обречена.

**Где реальная возможность (что делать):**
1. **Дифференциация формата, а не цены.** Кейс [A-LuGei B0FD34T1NB](https://www.amazon.com/dp/B0FD34T1NB) — главное доказательство: 5 размеров (не 4), «177 items», «military-grade» framing → **8k продаж/мес всего при 3 980 отзывах**. Новичок с чётким УТП пробивается за <1 год.
2. **Под-ниша C (rotating / desk).** [SKYDUE 4.8★](https://www.amazon.com/dp/B0CGHKSMRM), вес 290 г → FBA лишь $5.52, review-moat в разы ниже (5.7k vs 48k). Высокая маржа, меньше конкуренции.
3. **Цвет/материал как ось дифференциации** — WOWBOX и A-LuGei множат SKU по цвету (dark blue, pink). Премиальный матовый/тонированный акрил или бамбук-комбо = чистое поле.
4. **Не входить в под-нишу B (Akro-Mils):** тяжёлый, дорогой FBA, реселл-ценовые войны.

**Рекомендованный продукт для запуска:** прозрачный/тонированный drawer-сет **5 размеров (28+ шт.)** с явным числом «организует N предметов» + опционально вращающийся desk-компаньон под кисти. Цель — $14.99–17.99, вес <900 г.
