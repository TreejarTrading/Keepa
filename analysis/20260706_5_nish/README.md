# Анализ 5 ниш: US / UK / DE / AE (06.07.2026)

Ниши: подушки на сиденье, льдогенераторы, desk pads, коврики под кресло, обувницы.

- `keepa_collect.py` — сбор данных Keepa API (Product Finder + product stats,
  бестселлеры + новинки с 01.02.2026, US/UK/DE). Требует `KEEPA_API_KEY`.
- `data/` — сырые JSON-выгрузки (30 запросов, 300 товаров).
- `build_report.py` — юнит-экономика (все fees, VAT, пошлины, фрахт),
  потолок закупки под маржу 25%, вердикты BUY/WATCH/SKIP, проекция на ОАЭ;
  пишет XLSX в `Products/`.

Итоговый отчёт: `Products/Анализ_5_ниш_US_UK_DE_AE_20260706.xlsx`
(лист «Методика и оговорки» — все допущения).
