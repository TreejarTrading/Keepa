# Products

Папка для XLSX-отчётов, которые генерирует Keepa MCP-сервер
(ручные запуски через `/mcp` и авторежим `keepa-auto`).

Отчёт по Amazon содержит три листа:
- **Анализ** — таблица решений по товарам (метрики, **комиссии Amazon: referral
  по категории + FBA**, вердикт BUY/WATCH/SKIP);
- **Характеристики** — фичи, описание, габариты, вариации;
- **Сводка** — метаданные запуска и счётчики вердиктов.

Отчёт по сорсингу в Китае (Amazon ↔ Китай) содержит четыре листа:
- **Сопоставление** — товар Amazon ↔ поставщик: площадка, степень совпадения,
  цена за ед. на нужном уровне MOQ, себестоимость landed, маржа, ROI, вердикт
  ЗАКУПАТЬ/ПРОВЕРИТЬ/ОТКАЗ;
- **Сценарии** — как меняются landed/маржа/ROI по уровням объёма (MOQ);
- **Пояснения** — что означает и как считается каждая колонка (на русском);
- **Сводка** — метаданные запуска и счётчики вердиктов.

Файлы `*.xlsx` не коммитятся в git (см. `.gitignore`).
