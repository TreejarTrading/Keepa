# Products

Папка для XLSX-отчётов, которые генерирует Keepa MCP-сервер
(ручные запуски через `/mcp` и авторежим `keepa-auto`).

Каждый отчёт содержит три листа:
- **Анализ** — таблица решений по товарам (метрики + вердикт BUY/WATCH/SKIP);
- **Характеристики** — фичи, описание, габариты, вариации;
- **Сводка** — метаданные запуска и счётчики вердиктов.

Файлы `*.xlsx` не коммитятся в git (см. `.gitignore`).
